## 증거를 해석하는 기준

| 증거 | 확인할 수 있는 것 | 그 증거만으로 확인할 수 없는 것 |
|---|---|---|
| 사용자 요청 | 필요한 동작과 허용한 작업 | 구현 완료·성능 수치 |
| 과거 assistant 완료 보고 | 당시 작업자가 보고한 결과 | 누락된 원인·모든 실패 경로 |
| 현재 소스·테스트 대조 | 규칙과 검사 대상이 현재 존재함 | 검사 재실행·실물 출력 |
| mock 전송 흐름 검사 | 순서·불확실 전송·기록 실패·재시도 경계 | 실제 프린터 처리량·종이 품질 |
| 숨긴 실제 Tk 생성자·입력 검사 | 위젯 생성·idle·입력 상태 | 육안 배치·모든 DPI의 가독성 |
| 시작 trace의 `mapped: true` | Tk가 창을 매핑한 상태 | 사람이 본 정상 디자인 |
| Windows 큐 조회 | 해당 Windows 큐의 관측 결과 | Canon에서 모든 종이가 나옴 |
| Canon 접수·완료 결과 | 해당 토큰 작업의 장비 상태 | 사람이 출력물을 검사함 |
| 사용자 실물 확인 | 그 시험 상황에서 종이가 출력됐음 | 모든 장비·모든 오류 조합 |
| 해시·크기·페이지 수 | 파일의 동일성과 구조 | 수학 내용과 단원 대응의 완전성 |

정확한 원인이 확정되지 않은 출력 순서 사건, 유실 Git 객체, 사후 ETA 정확도와 최근 VBS 검증 제한은 오류 기록에도 남겼습니다.

## 이번 문서 작업의 확인 범위

이번 작업은 문서 작성과 Git 공개 반영입니다. 세션·보고서를 다시 읽고, 현재 모듈·핵심 심볼·테스트 파일과 Git 버전을 대조했습니다. 문서의 상대 링크와 대상 파일, Markdown 제목·코드 블록, 다이어그램의 노드·연결을 검사했습니다. 공개본의 민감정보와 변경 파일 범위도 확인했습니다. 다이어그램의 실제 화면 렌더링을 새로 검사한 것은 아닙니다.

애플리케이션 코드를 바꾸지 않았습니다. 전체 회귀·GUI 실행·실물 인쇄를 새로 수행한 것처럼 검사 결과를 갱신하지 않았습니다. 과거 개인 정보가 포함될 수 있는 로컬 증거 원문도 함께 올리지 않습니다.
