# 빠른 인쇄기 자료 업데이트

코드는 Git 커밋으로, 자료는 Drive의 버전 이름과 PDF 해시로 식별합니다. 코드가 사용하는 단원평가와 교과서 카탈로그도 해시로 확인합니다. 아래 명령은 저장소 루트에서 실행합니다.

## 수신 PC에서 자료판 확인

```powershell
$printPython = ".\.venv\Scripts\python.exe"
$assets = "scripts/quick_printer_asset_sync.py"
& $printPython $assets status
& $printPython $assets plan-update --version <승인한-자료판>
```

Drive를 쓰려면 로컬 rclone 설정과 `quick_printer_asset_channel.local.json`이 필요합니다. 내려받은 목록을 검사할 때는 `--version` 대신 `--manifest <목록.json>`을 사용합니다. 외부 자료 폴더를 직접 검사할 때는 `--root <자료루트>`를 붙입니다.

| 상태 | 의미 |
|---|---|
| `current` | 검사한 파일이 목표 버전과 일치 |
| `ready` | 변경 다운로드를 준비할 수 있음 |
| `baseline_repair_required` | 기존 기준본에서 공급해야 하는 PDF가 없거나 내용이 다름 |
| `local_conflict` | 덮어쓸 경로가 알려진 이전 파일의 해시와 일치하지 않음 |
| `inventory_review_required` | 이전 목록에는 있고 새 목록에는 없는 경로의 처리가 미확정 |
| `catalog_incompatible` | 앱의 카탈로그 버전 또는 내용이 목표 자료판과 다름 |

## 새 판을 준비하고 전환

```powershell
& $printPython $assets stage-update --version <승인한-자료판> --destination <별도의-새-폴더>
& $printPython $assets activate-assets --root <준비한-폴더>
& $printPython $assets status
```

준비는 변경 객체만 다운로드합니다. 로컬에 이미 일치하는 파일을 새 폴더에 복사하고 모든 파일을 다시 확인하므로 자료 전체와 변경 다운로드를 담을 공간이 필요합니다. 전환 시 앱과 같은 Windows 중복 실행 잠금을 확인합니다. 창을 닫은 뒤 전환하고 정상적으로 다시 실행합니다. `QUICK_PRINTER_RELEASE_ROOT` 환경 변수로 사용 중인 경로를 관리하는 PC라면 해당 경로 설정을 직접 관리합니다.

`activate-assets --previous`는 이전 자료 경로로 돌아갑니다. 버전 관리된 이전 폴더는 다시 검사합니다. 각 버전은 별도 폴더에 있으므로 자료 파일을 되돌리기 위해 다시 다운로드할 필요가 없습니다.

위 명령은 **자료판을 전환**합니다. 앱 코드가 바뀌는 배포는 새 커밋을 별도 Git 작업 폴더에 받거나, 개인 수정이 없는 현재 브랜치에서 검증한 커밋으로 fast-forward합니다. ZIP 설치판은 새 폴더에 별도 설치합니다. 변경된 코드에서 자료의 호환 판정을 다시 실행합니다. 수신 PC의 Git 코드와 ZIP 설치판을 함께 전환하는 자동 런처는 추후 작업입니다.

## 새 자료가 생겼을 때

```powershell
& $printPython $assets plan-import --family ilsan --source-root <일산-기출-후보-폴더>
& $printPython $assets plan-import --family able --source-root <렉쳐노트-후보-폴더>
```

후보 폴더는 배포에 쓸 하위 폴더·파일명 구조를 따릅니다. 결과에서 추가·교체·동일 파일, PDF 페이지 수와 해시를 확인합니다. 일산은 자료 ID와 서버 별칭도 점검합니다. A:ble은 차시 번호와 풀세트 구성 및 순서를 점검합니다. `review_unrecognized`의 파일은 자동 등록 대상에서 빠지므로 원인을 확인합니다.

확정한 자료를 발행자 자료 루트에 반영한 뒤 앱에서 시험 인쇄 계획을 확인합니다. 교과서는 해당 교과서 카탈로그와 표지·단원 범위 검증을 먼저 완료합니다. 승인된 이전 기준 목록은 `--from-manifest`로 함께 제공합니다. 새 판에서 의도적으로 빠진 경로만 UTF-8 목록으로 작성해 `--retire-list`에 전달합니다.

```powershell
& $printPython $assets publish-version --version <새-자료판> --from-manifest <이전-배포-목록.json> --dry-run
& $printPython $assets publish-version --version <새-자료판> --from-manifest <이전-배포-목록.json>
```

발행 명령은 해시 이름으로 Drive에 PDF 객체를 저장하고 바이트를 확인한 뒤 그 버전의 목록을 고정합니다. 확인한 버전 이름을 수신 PC에 전달합니다. 기존 Drive 최신 목록을 보는 설치본은 원래 증분 채널을 계속 사용할 수 있습니다.

11월 r2와 기존 v1 채널을 통합해 공개하기 전에는 각각의 기존 목록으로 새 판 설치 계획을 검증합니다. r2 대비 필수 PDF 6개 불일치와 로컬·Drive 저동고 PDF의 7쪽 판본 결정이 남아 있습니다.

## 인쇄 예상 시간 평가

```powershell
& $printPython scripts/quick_printer_eta_report.py --since 2026-11-01
```

50건 미만과 이상을 나눠 오차를 집계하고, 보류나 작업 추가 등으로 중간에 조건이 바뀐 실행은 따로 표시합니다. 새 이력은 25·50·75% 시점의 오차를 포함합니다. 표본에서 구분지·OMR을 별도로 학습하는 후보가 개선 기준을 통과하지 않아 기존 계산식을 사용합니다.
