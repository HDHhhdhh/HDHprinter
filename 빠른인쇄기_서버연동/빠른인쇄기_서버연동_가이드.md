# 빠른 인쇄기 서버 연동

학원 서버에서 오늘 배정한 시험을 CSV로 내려받아 빠른 인쇄기의 `대량주문서` 탭에서 한 번에 작업 큐로 추가하기 위한 규격입니다.

## 서버가 읽을 파일

- `빠른인쇄기_등록_테스트목록.csv`: 빠른 인쇄기에 현재 등록된 테스트 전체 목록
- `빠른인쇄기_서버주문_양식.csv`: 서버가 생성할 주문 CSV의 최소 양식

등록 목록의 `자료ID`를 서버 DB에 저장합니다. 화면 이름이나 로컬 절대 경로로 시험지를 식별하지 마세요. `자료ID`는 자료유형과 원본 폴더 내 상대경로가 유지되는 동안 동일합니다.

2026-09에 등록한 일산기출 공수2·미적분1 중간고사 34종은 서버의 `t_ilsan_past_...` 시험 ID도 직접 읽을 수 있습니다. 서버 CSV의 `자료ID` 열에 이 값을 넣거나 열 제목을 `서버시험ID`, `시험ID`, `파일코드` 중 하나로 사용하면 됩니다. 앱은 이를 정확한 `QT-ILSAN-...` 자료ID로 변환하여 큐와 영구 이력에 기록합니다. 공수2 상 6회차 백석고의 서버 시험 ID는 `t_ilsan_past_gongsu2_high_midterm_006`입니다.

## 서버가 출력할 CSV

```csv
주문번호,자료ID,학생이름,부수,메모
ASSIGN-20260828-001,QT-UNIT-0123456789ABCDEF,한동훈,1,
ASSIGN-20260828-002,QT-SCHOOL-0123456789ABCDEF,한동훈,1,
ASSIGN-20260828-003,QT-REVIEW-0123456789ABCDEF,장규리,1,
ASSIGN-20260909-001,t_ilsan_past_gongsu2_mid_high_midterm_001,장규리,1,
```

- `주문번호`: 서버의 배정 고유번호. 작업 큐 표시와 오류 추적에 사용합니다.
- `자료ID`: 등록 테스트 목록의 `QT-...` 값 또는 위 신규 일산기출 34종의 `t_ilsan_past_...` 서버 시험 ID를 사용합니다.

빠른 인쇄기는 한 CSV에서 생성된 블록을 `학생이름` 가나다순으로 안정 정렬합니다. 같은 학생의 자료 순서는 CSV 상대 순서를 유지하며 학생이름이 없는 행은 뒤에 놓습니다.
- `학생이름`: 이름 구분지에 인쇄할 이름입니다.
- `부수`: 빈칸이면 1부입니다.
- `메모`: 앱의 인쇄 선택에는 영향을 주지 않는 서버용 비고입니다.

CSV는 `UTF-8 BOM`을 권장합니다. 빠른 인쇄기는 UTF-8 BOM과 CP949를 모두 읽습니다.

## 이름 구분지 순서

같은 학생의 여러 시험은 CSV에서 연속 행으로 배치하세요.

```text
한동훈 시험 A
한동훈 시험 B
장규리 시험 C
```

이 순서로 가져오면 `한동훈 이름 구분지 - 시험 A - 시험 B - 장규리 이름 구분지 - 시험 C`로 인쇄됩니다. CSV에 학생이름이 하나라도 있으면 이름 구분지 기능이 자동으로 켜집니다.

이름 구분지를 사용하는 주문 묶음에서는 백지리뷰/OMR 같은 고정 용지를 제외한 모든 행에 학생이름을 넣으세요. 이름이 빠진 일반 블록이 있으면 인쇄 전 검증에서 알려 주고 전송을 막습니다.

학군지기출과 일산기출은 앱의 기존 규칙에 따라 각 시험지 앞에 가로 OMR 1장이 자동으로 들어갑니다.

## 교재 주문도 함께 내릴 때

테스트는 `자료ID` 한 칸으로 지정합니다. 교재는 기존 상세 주문 열을 사용합니다. 전체 열 양식은 프로젝트 루트의 `빠른인쇄기_대량주문서_양식.csv`에 있습니다.

```csv
주문번호,자료유형,과목,레벨,회차,문서,인쇄구성,시작번호,끝번호,개별번호,부수,묶음,프린터프로필,파일경로,메모,자료ID,학생이름
BOOK-001,A:ble,기하,,,교재,차시별,,,"3-5",1,아니오,,,,,한동훈
BOOK-002,APEX,공통수학1,,,교재,차시 별,,,"1,2,5",1,아니오,,,,,장규리
```

테스트와 교재 행을 한 CSV에 섞어도 됩니다. `자료ID`가 입력된 행은 해당 ID가 선택을 전부 결정하고, 교재 행은 기존 자료유형/과목/구성 열을 사용합니다.

## 빠른 인쇄기 사용 순서

1. `대량주문서` 탭에서 서버가 내려준 CSV를 선택합니다.
2. 오류가 0건인지 확인하고 주문 블록을 추가합니다.
3. 작업 큐 순서와 학생 이름을 확인합니다.
4. 인쇄를 시작합니다.

등록 목록에 없는 자료ID, 누락된 PDF, 잘못된 교재 범위가 한 건이라도 있으면 어떤 블록도 추가하지 않습니다. 오류 행을 수정한 뒤 다시 가져오면 됩니다.

## 카탈로그 갱신

테스트 파일이 추가되거나 경로가 바뀌면 다음 명령으로 목록을 다시 생성해 서버에 반영합니다.

```powershell
python scripts/export_quick_printer_server_catalog.py
```

기존 파일의 상대경로가 바뀌지 않았다면 기존 `자료ID`는 유지됩니다.
